## Contexto

Qué problema o fuerza obliga a decidir. Qué restricciones aplican (constitución, specs,
negocio). Escríbelo para alguien que llega al proyecto dentro de un año.

## Decisión

Qué se decidió, en una o dos frases directas. Después, el detalle necesario para aplicarla.

## Alternativas consideradas

- **Alternativa A.** Por qué no se eligió.
- **Alternativa B.** Por qué no se eligió.

## Consecuencias

- **Positivas:** qué se gana.
- **Negativas:** qué se pierde o qué costo se acepta.
- **Acciones derivadas:** qué tienen que hacer las specs siguientes por esta decisión.
